
# y4p

**Wayland統合型クリップボード・インフラストラクチャ**

`y4p` は、Waylandの `ext-data-control-v1` にネイティブ対応した、高性能かつスタンドアロンのクリップボードマネージャーです。監視・提供・永続化を単一のバイナリに統合。ゼロコピーの `sendfile(2)` 配信とSQLite（WALモード）による履歴管理により、数バイトのテキストから70MBを超える巨大なロスレス画像まで、デスクトップの体感速度を損なうことなく処理します。

---

## 主な機能

- **Unified Daemon**: 単一のバックグラウンドプロセスが監視・提供・永続化を一括管理。ツール間の同期ズレが発生しない。
- **Hybrid Storage**: メタデータとテキストは高速検索可能なSQLiteへ、巨大バイナリは重複排除された `~/.cache/y4p/` へ自動振り分け。
- **Pin Protection**: `pin`/`unpin` によるレコード保護。固定（Pin）したレコードは `Y4P_MAX_HISTORY` を超過しても自動ローテーション削除の対象外。
- **Stable ID System**: 表示順に依存しない不変のデータベースID。RofiやFzf、`awk` 等の外部スクリプトからレースコンディションを排した正確なアイテム特定が可能。
- **Strict CLI**: 未定義のフラグを「それらしく解釈」せず即座に拒絶する、厳格な引数解析エンジン。無人実行されるスクリプトでも安全。
- **Security Focused**: ディレクトリ権限（700）・ファイル権限（600）の強制、パスワードマネージャー由来などの機密MIMEタイプの自動フィルタリング。

## クイックスタート

### 1. ソースからのビルド
```bash
cargo build --release
sudo cp target/release/y4p /usr/local/bin/
```

### 2. デーモンの起動
監視およびIPCリスナーを初期化します。
```bash
y4p daemon
```

### 3. 基本操作
```bash
y4p list 0-50 --id      # 不変IDを使用して履歴を表示
y4p copy-to --id 42     # IPC経由で特定のアイテムを復元
y4p pin 3               # 直近から3番目のアイテムをローテーションから保護
y4p search "invoice" -i # キーワード検索（不変ID表示）
```

### 4. シェル補完
Zsh補完は `completions/_y4p` として同梱されています。`compinit` 実行前に対象ディレクトリを `fpath` に追加してください。
```zsh
fpath+=(/path/to/y4p/completions)
```

## コマンドリファレンス

| コマンド | 説明 |
| :--- | :--- |
| `daemon` | バックグラウンド監視およびIPCソケットリスナーを開始。 |
| `status` | IPC経由でデーモンに稼働状況を問い合わせて表示。 |
| `pause` / `resume` | クリップボードの監視を一時停止／再開（プライベートモード）。 |
| `list` | 履歴のメタデータを表示。範囲指定、`--raw`、`--id` に対応。 |
| `search` | SQLiteインデックスを利用したキーワード検索。複数キーワードのAND検索に対応。 |
| `copy-to` | 指定したレコードをIPC経由でクリップボードに復元。インデックスまたは `--id` を受け付け。 |
| `show` | レコードの詳細を確認。`--raw` でバイナリの直接抽出が可能。 |
| `store` | 標準入力からデータを吸い出し、DB保存と同時にクリップボードへ同期。 |
| `paste-from` | DBを介さず、現在のシステムクリップボードに直接アクセスして出力。 |
| `pin` / `unpin` | レコードを自動ローテーション削除から保護／解除。 |
| `delete` | 特定のレコードを永続ストレージから物理的に削除（Pin状態に関わらず可能）。 |
| `wipe` | Pin留めされたものを含む全履歴を消去し、SQLiteのVACUUMを実行。`--force`（`-f`）が必須。 |

各コマンドの詳細なフラグ一覧は `y4p help` を参照してください。

## 環境変数

| 変数名 | デフォルト | 説明 |
| :--- | :--- | :--- |
| `Y4P_MAX_HISTORY` | `256` | 保持する未Pin履歴件数の上限。不正値・0・負数の場合はデフォルト値にフォールバック。 |

```bash
export Y4P_MAX_HISTORY=500
y4p daemon
```
